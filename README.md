# Seventh Stores Shopify Theme

Shopify Online Store 2.0 theme for Seventh Stores. This theme is based on Dawn `15.4.1` and keeps the standard Shopify theme architecture while adding a Vite-powered frontend layer for custom CSS and JavaScript.

## Tech Stack

- Shopify Liquid, JSON templates, sections, snippets, and theme settings
- Shopify Theme CLI for local preview and theme pushes
- Vite `5`
- Tailwind CSS `4` with the `ts:` utility prefix
- Swiper `11` for slider behavior
- Dawn base assets and custom cart drawer enhancements

## Requirements

- Node.js and npm
- Shopify CLI
- Access to the target Shopify store/theme

## Getting Started

Install dependencies:

```bash
npm install
```

Start Shopify Theme CLI and Vite together:

```bash
npm run dev -- --store your-store.myshopify.com
```

Build the Vite assets:

```bash
npm run vite:build
```

Build frontend assets and push the theme:

```bash
npm run deploy -- --store your-store.myshopify.com
```

Log out of Shopify CLI if you need to switch accounts:

```bash
npm run logout
```

## Available Scripts

- `npm run dev` - Runs `shopify theme dev` and `vite` in parallel.
- `npm run deploy` - Runs a Vite production build, then pushes the Shopify theme.
- `npm run shopify:dev` - Runs Shopify Theme CLI preview only.
- `npm run shopify:push` - Pushes the theme through Shopify CLI.
- `npm run vite:dev` - Runs Vite only.
- `npm run vite:build` - Builds the frontend entrypoints into Shopify assets.

## Project Structure

```text
assets/      Compiled Vite assets, Dawn assets, Shopify CSS, JavaScript, icons, and images
config/      Global theme settings and saved theme data
frontend/    Source CSS and JavaScript for the Vite build
layout/      Theme and password layouts
locales/     Storefront and theme editor translations
sections/    Online Store 2.0 sections and section groups
snippets/    Reusable Liquid snippets
templates/   JSON and Liquid templates
```

## Frontend Workflow

The main Vite entrypoints are:

- `frontend/entrypoints/main.css`
- `frontend/entrypoints/main.js`

`main.css` imports `frontend/web/styles/global_styles.css` and Tailwind using the `ts:` prefix. Keep Tailwind utilities prefixed, for example `ts:flex`, so they do not collide with Dawn or Shopify classes.

`main.js` imports:

- `frontend/web/scripts/global_script.js`
- `frontend/web/scripts/swiper_slider.js`
- `frontend/web/scripts/accordion.js`

The built files are loaded in `layout/theme.liquid` through `snippets/vite-tag.liquid`. That snippet is generated by `vite-plugin-shopify`; do not edit it directly. Run `npm run vite:build` after frontend changes so the generated asset references stay current.

## Theme Notes

- The theme metadata in `config/settings_schema.json` identifies the base as Dawn `15.4.1`.
- `layout/theme.liquid` keeps the required `{{ content_for_header }}` and `{{ content_for_layout }}` hooks.
- Header and footer are rendered through Shopify section groups.
- Cart drawer output is shared through `snippets/cart-drawer.liquid`; `sections/cart-drawer.liquid` renders that snippet for section refreshes.
- Cart drawer features include the free shipping progress bar and optional upsells controlled by theme settings.
- Custom slider behavior uses the `swiper-slider` custom element.
- Custom accordion behavior uses `accordion-element` and `accordion-item`.

## Development Guidelines

- Keep merchant-facing content configurable through section settings, blocks, or global theme settings.
- Prefer reusable snippets for repeated Liquid markup.
- Add or update locale keys in `locales/en.default.json` for storefront text.
- Keep frontend source changes in `frontend/`; let Vite generate the corresponding files in `assets/`.
- Do not manually edit generated Vite files or `snippets/vite-tag.liquid`.
- When changing cart behavior, preserve Dawn cart drawer IDs, custom elements, and section refresh hooks.
- Test collection filters, variant selection, cart drawer updates, quick add, and checkout handoff after changes that touch shared product or cart code.

## Deployment Notes

`.shopifyignore` excludes development-only files such as `package.json`, `package-lock.json`, `frontend/`, `node_modules/`, Git files, and Markdown files. This README is for local developer reference and is not uploaded to Shopify.

Before pushing a theme, run:

```bash
npm run vite:build
```

Then preview or deploy with Shopify CLI:

```bash
npm run shopify:dev -- --store your-store.myshopify.com
npm run deploy -- --store your-store.myshopify.com
```
